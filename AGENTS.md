# Development instructions

This repository is a development skeleton. Implement docs/CODEX-TDD-PROMPT.md using
RED/GREEN/REFACTOR in small steps. Never describe placeholder services as implemented.
No runtime networking. No automatic signup decisions or application-specific blacklist.
Keep the public DTOs independent of MaxMind classes. Prefer typed, immutable results.
Tests must be offline with synthetic fixtures. Keep database licenses distinct from MIT.
Do not publish, tag releases or push unless explicitly requested. Verify supported PHP
and Laravel versions before claiming compatibility. No sub-agent workflow is required.
