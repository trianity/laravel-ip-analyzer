# MMDB test fixtures

No production databases are bundled. During TDD add small synthetic Country and ASN
MMDB fixtures from an appropriate, verified source or generate them. Record source URL,
revision, license, required notices and the expected IP records here. Tests must be
deterministic, offline, and must not depend on the live location of public IPs.
Do not relabel third-party fixtures as MIT. Narrowly exempt their exact paths from
.gitignore and .gitattributes when adding them; keep production MMDB files excluded.
